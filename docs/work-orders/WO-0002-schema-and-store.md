## 1. Objective
A `Store` class that creates the DESIGN §3.2 schema idempotently in
`store/argus.duckdb`, writes/reads Parquet-backed bar tables and small
catalog tables with parameterised SQL, a working `argus init-store`, and
the ticker-normalisation module every provider in group P0-C depends on.

## 3. Exclusions
No provider implementations (no HTTP), no universe logic,
no adjustment logic, no YAML config, no changes under `docs/`.

## 4. Design constraints
DuckDB ≥ 1.0 and polars only. `Store.read()` accepts SQL with `?`
placeholders and a params list; any attempt to format external values into
SQL is a defect. `upsert()` uses `INSERT … ON CONFLICT DO UPDATE` (DuckDB
syntax) within a transaction. `write_bars_raw()` partitions by
`year=YYYY`, dedupes on `(symbol,date,source)` keeping the latest
`ingested_at`, and writes with `pl.DataFrame.write_parquet` into a
temporary file then atomic rename. `init_schema()` is safe to call
repeatedly and records `schema_version` once. All timestamps UTC.
`store_dir` is created if missing with mode 0750.

## 6. Acceptance criteria
- **AC1** — `argus init-store` creates `store/argus.duckdb` and all 18 tables/views (test_all_design_tables_present; operator check listing `SHOW TABLES`).
- **AC2** — Re-running `argus init-store` changes nothing (test_init_idempotent).
- **AC3** — Parquet partitions appear under `store/parquet/bars_raw/year=YYYY/` after a write (test_bars_raw_roundtrip_and_dedupe).
- **AC4** — No SQL string formatting with external input anywhere in `argus/data/` (Auditor grep for f-strings/`%`/`.format` adjacent to `execute`).
- **AC5** — `members_on()` returns correct point-in-time sets (test_members_on).
- **AC6** — Ticker round-trips and rejections pass (test_tickers.py).

## 8. Implementer notes
Column types: DATE for dates, DOUBLE for prices/volumes, TIMESTAMP (UTC)
for timestamps, TEXT for strings, JSON stored as TEXT. Create the parquet
directories on `init_schema()` so the views resolve even when empty (an
empty directory needs an empty parquet file with the right schema — write
one on init).
