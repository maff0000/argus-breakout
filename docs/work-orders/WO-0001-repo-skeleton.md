## 1. Objective
An installable `argus` package with typed settings, structured logging, a
typer CLI skeleton, lint/test tooling and a lockfile, such that
`uv venv --python 3.12 .venv && uv sync --all-extras && uv run ruff check .
&& uv run python -m pytest -q` passes offline and `argus --version` prints
the version (ADR-0007, AMD-0003). No data code yet.

## 3. Exclusions
No `argus/data/`, no providers, no DuckDB code, no commands beyond the empty sub-app objects and the `init-store` stub, no YAML config files, no
systemd units, no README changes, no changes under `docs/` (the Delivery
Controller adds evidence), no `.env`.

## 4. Design constraints
The build backend is `hatchling` and is the only build-time dependency
permitted beyond PID §8.1's list (AMD-0007). PID §8.1–8.3 and §8.9,
**including the ADR-0008 portability constraints**
(no absolute paths; writes only under the configured store/out dirs; logs to
stdout; nothing importing or shelling out to `uv`/`systemd`/`apt`).
Secrets are `pydantic.SecretStr`; `Settings.__repr__`
must not reveal them. `require()` raises `ConfigError` whose message lists
every missing field name, nothing else. Logging writes JSON lines to stdout
only. No network access anywhere in this Work Order.

## 6. Acceptance criteria
- **AC1** — `uv venv --python 3.12 .venv && uv sync --all-extras` succeeds and `.venv/bin/python --version` reports 3.12.x (operator check, output filed) (AMD-0003).
- **AC2** — `uv run ruff check .` reports no violations (CI lint job; operator check).
- **AC3** — `uv run python -m pytest -q` passes with no `.env` present (tests above).
- **AC4** — `argus --version` prints `0.1.0` (test_version).
- **AC5** — `uv.lock` exists and `uv sync --all-extras` from a clean checkout succeeds (operator check) (AMD-0003).
- **AC6** — `gitleaks detect --source .` clean (CI; operator check).
- **AC7** — No absolute path literals and no `uv`/`systemd`/`apt` references in `argus/` (Auditor: `grep -rnE "['\"]/(srv|etc|usr|opt|home|var)/" argus/` and `grep -rniE "\b(uv|systemd|systemctl|apt-get)\b" argus/` both empty) (ADR-0008, AMD-0004).

## 8. Implementer notes
Read PID §8.1–8.3 first; the signatures there are binding. Keep `cli.py` free of business logic; sub-apps are empty `typer.Typer()` objects in `argus/commands/` that later Work Orders register commands onto from their own modules (PID §8.7 command-module rule, AMD-0002). Do not add dependencies beyond PID §8.1. Use `uv` for everything: `uv add` edits `pyproject.toml`, `uv lock` writes `uv.lock`; never `pip install` into the venv.
