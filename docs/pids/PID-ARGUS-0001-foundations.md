**Status:** Approved · **Version:** 1.0 (2026-10-19) · **Parent:** `PID.md` (PID-ARGUS-0000) §6 row 1

## 1. Identity
As `PID.md` §1. `PROJECT_ROOT=/srv/argus-breakout`, `maff0000/argus-breakout`.

## 2. Purpose
Stand up the data foundation every later phase depends on: a reproducible
local store of adjusted daily bars for the S&P 500 (point-in-time
membership) and the benchmark/sector ETFs, with corporate actions,
earnings/ex-dividend events, nightly ingestion from Polygon, a 10-year
bootstrap, IBKR reconciliation and implied volatility, and an unattended
nightly pipeline.

## 3. Target Outcome
On the delivery host: `argus nightly --date <T>` completes unattended for
three consecutive trading days; the store holds ≥ 10 years of bars for
every current member and ETF; point-in-time membership queries work for any
date since 2015-01-01; nightly reconciliation against IBKR breaches on
< 1% of sampled fields; every member has a GICS sector and industry group.

## 4. Users
The Delivery Controller and Architect (via CLI, logs and evidence). No
end-user surface in this phase.

## 5. Presentation Target
`FUNCTIONAL_ONLY`. Outputs are a CLI, DuckDB/Parquet files and JSON logs.
Auditors verify by running commands and inspecting the store, not a
browser.

## 8. Architecture — binding interfaces shared by all Work Orders

### 8.1 Package and tooling
- Python **3.12**. `pyproject.toml` (PEP 621) with `[project] name="argus"`,
  console script `argus = "argus.cli:app"`. Dependencies (minimum
  versions, pin exact in `requirements.lock` generated by WO-0001):
  `polars>=1.0`, `duckdb>=1.0`, `pyarrow>=15`, `httpx>=0.27`,
  `pydantic>=2.7`, `pydantic-settings>=2.3`, `typer>=0.12`,
  `structlog>=24`, `pyyaml>=6`, `tenacity>=8`. Dev: `pytest>=8`,
  `pytest-cov`, `respx` (httpx mocking), `ruff>=0.5`, `pre-commit` not
  used (git hook is committed directly). Optional extras:
  `ibkr = ["ib_async>=1.0"]`, `bootstrap = ["yfinance>=0.2.50"]`.
- `ruff` config: line length 100, `select = ["E","F","I","B","UP","S"]`
  (S = bandit security rules), `S101` ignored in tests only.

### 8.2 Settings (`argus/settings.py`)
```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_prefix="", extra="ignore")
    argus_store_dir: Path = Path("store")

    llm_api_key: SecretStr | None = None

    llm_model_review: str | None = None

        """Raise ConfigError listing every named field that is None/empty."""

class ConfigError(RuntimeError): ...

```
Providers call `settings.require("polygon_api_key")` in their constructor.
Secrets are `SecretStr`; `repr`/logs never reveal them.

### 8.3 Logging (`argus/logging.py`)
`configure_logging(level)` → structlog JSON to stdout, UTC ISO timestamps,
fields `ts, level, event, run_id, step, symbol?`. A processor redacts any
value matching `(?i)(api[_-]?key|token|secret)=\S+` and any string equal
to a configured secret.

### 8.4 Ticker normalisation (`argus/data/tickers.py`)
```python
CANONICAL = re.compile(r"^[A-Z][A-Z0-9.\-]{0,9}$")
def normalize(symbol: str, source: Literal["polygon","yfinance","ibkr","fmp","wikipedia","hanshof"]) -> str
def to_provider(symbol: str, source: ...) -> str
def is_valid(symbol: str) -> bool
```
Canonical form uses `.` for share classes (`BRK.B`, `BF.B`). Polygon and
FMP use `BRK.B`; yfinance uses `BRK-B`; IBKR uses `BRK B`. Unknown input
that fails `CANONICAL` after normalisation raises `ValueError`.

### 8.5 Store (`argus/data/store.py`, `argus/data/schema.py`)
```python
class Store:
    def __init__(self, store_dir: Path) -> None
    def connect(self, read_only: bool = False) -> duckdb.DuckDBPyConnection
    def init_schema(self) -> None                  # idempotent; applies schema.py DDL, records schema_version
    def upsert(self, table: str, df: pl.DataFrame, keys: list[str]) -> int   # returns rows written
    def read(self, sql: str, params: list | None = None) -> pl.DataFrame      # parameterised only
    def write_bars_raw(self, df: pl.DataFrame) -> int   # dedupe on (symbol,date,source); parquet partition year=YYYY
    def read_bars_raw(self, symbols: list[str] | None, start: date, end: date, source: str | None) -> pl.DataFrame
    def write_bars(self, df: pl.DataFrame) -> int       # replaces the affected (symbol) partitions
    def read_bars(self, symbols: list[str] | None, start: date, end: date) -> pl.DataFrame
    def members_on(self, d: date) -> list[str]          # from membership
    def log_ingest(self, date: date, source: str, rows: int, status: str, detail: str = "") -> None
```
Parquet layout: `store/parquet/bars_raw/year=YYYY/*.parquet`,
`store/parquet/bars/symbol=<SYM>/*.parquet`; small tables live inside
`store/argus.duckdb`. DDL is the schema in DESIGN.md §3.2, exactly.

### 8.6 Provider contract (`argus/data/providers/base.py`)
```python
class RateLimiter:            # token bucket; calls_per_minute; blocks (sleeps) when exhausted
class ProviderError(RuntimeError)
class BarsProvider(Protocol):
    source: str; basis: Literal["unadjusted","split","split_div"]
    def daily_bars(self, symbols: list[str], start: date, end: date) -> pl.DataFrame  # canonical columns
```
Canonical bar columns: `symbol, date, open, high, low, close, volume`
(float64; date as `pl.Date`). Every provider normalises tickers on the way
out and validates them.

### 8.7 CLI (`argus/cli.py`, typer)
```
argus --version
argus init-store                         # Store.init_schema
argus universe refresh [--date]          # WO-0003
argus ingest polygon --date D | --backfill START END          # WO-0004
argus ingest polygon-actions --since D                        # WO-0004 (splits, dividends)
argus ingest bootstrap --start D [--end D] [--symbols ...]    # WO-0005
argus events refresh --days 45                                # WO-0006
argus adjust materialise [--symbols ...]                      # WO-0007
argus ibkr reconcile --date D [--sample 20]                   # WO-0008
argus ibkr iv --date D                                        # WO-0008
argus nightly --date D [--skip-ibkr]                          # WO-0009
```
Every command exits non-zero on failure and logs `status=failed` to
`ingest_log` where a date applies.

### 8.9 Security rules (binding, from `PID.md` §9)
No secrets/hosts/ports/account ids in source, tests, fixtures, logs or
docs. SQL parameterised. Symbols validated. UTC canonical. Config via
environment only.
