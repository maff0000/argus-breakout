# WO-0007 — Spec gaps and residuals (for the Architect)

1. **F2 — flag exclusion is per (symbol, day, source).** A flagged or quarantined Polygon row can be replaced by an independent yfinance row for the same day. Live: 51 of the 128 flagged symbol-days were published this way and all 51 agree with Polygon to within 1e-5 relative, i.e. the jumps were real earnings-type moves. Where yfinance has no row (new nightly days before a yfinance refresh), a real >25% move is withheld from `bars`. Ratify, or amend the AMD-0018 §2A wording (e.g. exclusion by default for data faults only, `jump_unexplained` informational).
2. **F1 — dividend prior-close tolerance** of 5 calendar days (WO §4 says "missing → skip and warn"); a 2–5 day gap silently uses a stale close. Ratify or ask for warn-on-stale.
3. **Dividend basis vs splits** (open since the first Implementer report): dividend amounts are used as stored against the split-adjusted prior close. If a source stores as-paid amounts and a split came later, the yield is wrong. The WO formula does not address it; needs a rule or a data check.
4. **`bars_outside_membership` is noisy by construction** (3,403 warnings): it counts history before a symbol joined the index and Polygon rows after a member left. The WO/AMD text is literal; a materialise report that separates "before first membership" (benign) from "after final end without rename continuity" (the §2F hazard) would be more useful.
5. **Float32 storage of prices** makes published closes differ from Polygon's float64 by up to 5e-8 relative; AC2 "exactly" should say "to float32 precision" or the column type should be revisited.
6. **Scope:** helpers not named in §2 (`source_disagreements`, `resolve_splits`, `resolve_dividends`, `Store.read_ingest_verdicts`, `Store.read_bar_flags`, optional `Store(config_dir=)`) sit in §2 files (ruling 8). No `SCHEMA_VERSION` change (4 arrives from WO-0012).
7. **Per-row split baseline** (a deliberate generalisation of the WO's per-source wording); the `split_case` fixture does not discriminate it from per-source, the synthetic test does.
8. **Merge note:** the branch merges `main` (WO-0012) before audit; conflicts in `store.py` (both loggers kept: structlog `log`, stdlib `_stdlog`) and `DELIVERY-LOG.md` were resolved by the DC.
